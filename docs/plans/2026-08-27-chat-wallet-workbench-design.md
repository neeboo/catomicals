# Catomicals 聊天钱包工作台设计

## 目标

Catomicals 的主界面是一张持续对话的工作台。用户用自然语言描述目标，钱包把交易检查、配置审查和签名意图做成会话内的受控卡片。用户核对权威数据后，再通过桌面界面确认配置，或通过 Passkey 批准交易。

产品界面沿用用户提供的 Codex 桌面截图：左侧管理会话和入口，中间承载对话，右侧按需打开浏览器与工具。会话始终拥有最大可用空间。

## 视觉依据

- 用户提供的 Codex 桌面截图：窄左栏、宽对话、按需出现的右侧页签。
- DeepSeek Harness `packages/web`：执行器接入和 Cordis 插槽的组织方式。
- Catomicals 当前黑白灰样式、间距、圆角、字体和 Tabler Icons。

参考项目只提供布局和交互依据。Catomicals 继续使用自己的安全合同、运行时和样式体系。

## 信息架构

### 左栏：会话和设置入口

- 顶部放产品标识、新建会话和简短搜索入口。
- 中段显示真实会话。当前钱包节点只有单个内存会话时，不伪造多会话持久化。
- 底部保留账户入口、设置入口和一行紧凑状态。
- 设置从左栏底部进入，打开独立设置视图。插件、健康检查和运行配置不占用对话顶部。
- 登录、Passkey、钱包或 YubiKey 身份入口保留位置，等身份服务合同确定后再接入。

### 中栏：连续对话

- 顶部只显示当前会话名称和必要的窗口操作，不放插件工具栏。
- 正文显示用户消息、执行器回复、工具事件和受控卡片。
- 输入框固定在底部。输入框附近可以选择 Codex、DeepSeek Harness 或 Claude Code。
- 模型、推理等级、工作目录和可用状态以桌面宿主的真实探测结果为准。
- 已创建的执行器会话保留创建时的配置；配置变化通过 `restartImpact` 提醒用户新建或重启会话。
- 钱包动作只在消息里展示权威引用，聊天文本不能批准配置、批准交易、签名或广播。

### 右栏：按需工具页签

- 默认折叠。用户从右侧工具入口打开浏览器、交易检查、签名意图、安全状态或资产发行。
- 右栏使用一层页签，不重复展示插件目录或多层卡片导航。
- 浏览器由 Electron `WebContentsView` 承载。Web 页面只负责选择页签、同步容器边界和发起公开网址导航。
- 关闭右栏后，中间对话恢复全部可用宽度。
- 窄窗口下右栏变为覆盖式抽屉，不压缩输入框到不可用宽度。

## 设置页

设置页按 Cordis 固定插件目录组织：

- 显示插件名称、版本、隔离状态和最近一次健康检查；
- 从插件的 settings schema 生成紧凑表单；
- 读取当前 last-good 配置，秘密字段只显示“未设置、已设置、已变更”；
- 提交时先校验补丁，再创建待确认的设置审查；
- 审查卡展示字段差异、权限变化、重启影响和有效期；
- 用户在桌面界面确认后，宿主重新读取插件版本、当前摘要和秘密引用，再运行迁移与健康检查；
- 通过后原子提升为 last-good，失败时保留原配置。

代理可以读取插件、检查健康状态、校验补丁和创建设置意图。确认设置只存在于固定桌面界面，不进入 MCP。

## 会话内受控卡片

第一版使用固定组件白名单，不引入完整的 `json-render`：

- `plugin_settings_diff`：绑定 `review_id`，从桌面宿主重读设置审查；
- `health_status`：绑定 `plugin_id`，从桌面宿主重读健康状态；
- `review_card`：绑定 `review_id` 或 `intent_id`，从权威来源重读审查；
- 后续的交易摘要、费用图表和策略差异继续沿用同一引用模型。

代理输出的 `ui_block` 只能包含组件名和引用 ID。金额、地址、配置旧值、配置新值、交易输出和确认结果都由宿主或钱包节点重读。卡片动作只负责打开权威审查；批准、签名和广播仍走各自的受信界面。

## 执行器和 MCP

- Codex、DeepSeek Harness 和 Claude Code 共享同一套会话状态和受控消息协议。
- 桌面宿主负责探测命令、版本和能力，并记录实际模型、推理等级、工作目录与重启影响。
- MCP 关闭时，执行器只能聊天。
- MCP 开启时，钱包工具继续连接 walletd；Cordis 配置工具连接桌面宿主的本地受限控制通道。
- 配置 MCP 只提供目录读取、manifest 读取、schema 读取、健康检查、补丁校验和设置意图创建。
- MCP 不提供配置确认、交易批准、FROST 份额释放、签名或广播。

## 响应式和可用性

- 桌面左栏约 260 至 280 像素，右栏约 340 至 420 像素，中栏自适应。
- 左栏、右栏都能折叠，输入框和最近消息始终可见。
- 图标仅用于导航和状态，文字承担主要说明。
- 空状态保持简短，不重复堆放功能卡片。
- 错误信息直接说明失败位置和下一步，不用模糊的兜底提示掩盖真实状态。

## 验收条件

- 会话顶部没有插件工具栏；工具统一在右侧折叠区。
- 左栏底部可以进入设置页，也可以返回会话。
- 设置页能读取真实 Cordis 插件、当前配置、schema 和健康状态。
- 修改配置只能创建审查，确认后才改变 last-good。
- 执行器选择器显示真实探测状态，不使用硬编码的 `not-connected` 数据。
- 浏览器页签能打开、关闭、导航，并跟随右栏尺寸更新 Electron 面板边界。
- 三种受控卡片只消费引用 ID，并在渲染时重读权威数据。
- Web 测试、类型检查和生产构建通过；Electron 与 Web 集成状态需要实际启动验收。
