# Catomicals 聊天钱包工作台设计

## 目标

把现有以路由和表单为中心的钱包页面改造成连续对话工作台。用户的主要路径是：描述目标、查看钱包生成的交易或意图、核对风险、通过 Passkey 批准，再观察 FROST 签名状态。

## 视觉依据

- 用户提供的 Codex 桌面截图：左侧会话、中间对话、右侧上下文信息。
- DeepSeek Harness `apps/web` 及 `packages/client/ui-*`：Cordis 插槽驱动的 `sidebar | conversation | details` 三栏结构。
- 只参考布局、交互层次和组件边界，不复制 DeepSeek Harness 的运行时。

## 信息架构

### 左栏：钱包与会话

- 产品标识、网络和节点在线状态。
- 新建会话入口。
- 会话列表；当前版本映射钱包节点提供的单一内存会话，并保留扩展多会话的结构。
- 工具入口：交易检查、发行准备、待批准意图。
- 底部显示 FROST 门限、Passkey 数量和本地签名者。

### 中栏：连续对话

- 顶部显示当前会话和安全边界。
- 对话正文直接使用钱包节点的真实消息。
- 空状态提供三个可执行起点；选择后打开对应右栏工具。
- 输入框固定在底部，发送到现有聊天接口。
- 钱包动作以可检查的意图卡片嵌入消息，不在聊天命令中直接批准或签名。

### 右栏：上下文详情

- `交易`：输入未签名交易和 ordered prevouts，调用现有交易检查接口，展示费用、RBF、输入输出及警告。
- `意图`：展示待批准及最近意图，进入现有 Passkey 批准流程。
- `安全`：展示 Inquisition、OP_CAT、FROST、Passkey 和本地签名者的实时状态。
- `发行`：明确当前协议仍在研究/实现中，先收集发行目标，不伪造链上能力。

## 交互与响应式

- 桌面默认三栏：左栏约 272px，中栏自适应，右栏约 360px。
- 右栏可折叠；窄屏下左右栏变为覆盖式抽屉，中间对话保持主界面。
- 所有图标使用 Tabler Icons；不用字符图标或手绘 SVG。
- 颜色沿用 Catomicals 的黑白灰体系，减少大写微标签，提高正文可读性。

## 边界

- 当前后端只有单个内存会话，前端不伪造多会话持久化。
- DeepSeek Harness/Codex Harness 连接留在工具注册边界，本次不引入它们完整运行时。
- 发行工具只展示规划入口；交易检查、意图、Passkey 和节点状态必须使用真实现有接口。
